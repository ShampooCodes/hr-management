# hr-management

A simple HR management web app. Admins manage staff, leaves, payroll, notices and tasks. Employees mark attendance, apply for leave and check their salary.

## Features
**Admin**
- Add, view and delete eimployees
- Approve or reject leave requests
- Generate monthly payroll (deducts salary for approved leaves)
- Post notices for everyone
- Assign tasks to employees and track their status

**Employee**
- check in and check out daily
- Apply for leaves and see its status
- View payroll history
- Read company notices
- View assigned tasks and update their status
